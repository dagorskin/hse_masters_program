# Магистратура НИУ ВШЭ

Домашние задания по программе магистратуры НИУ ВШЭ «Бэкенд-разработка и архитектура программных систем».

## Об обучении

- **Университет:** Национальный исследовательский университет «Высшая школа экономики».
- **Направление:** программная инженерия.
- **Программа:** «Бэкенд-разработка и архитектура программных систем».
- **Начало обучения:** сентябрь 2026 года; первый курс — 2026/2027 учебный год.

Основной профессиональный фокус — бэкенд-разработка на Python и архитектура программных систем.

В рамках обучения дополнительно изучаю C++. На втором курсе планирую изучать ещё один язык на выбор; предварительно рассматриваю Go.
