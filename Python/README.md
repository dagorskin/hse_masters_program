# Язык Python для разработчиков

Домашние задания по дисциплине «Язык Python для разработчиков» в рамках магистратуры НИУ ВШЭ «Бэкенд-разработка и архитектура программных систем».

**Преподаватель:** Руслан Шиманский.

[Об обучении и других разделах репозитория](../README.md)

Решения и материалы будут добавляться в репозиторий по мере работы над заданиями.

Каждое домашнее задание будет находиться в отдельной папке: `hw_1`, `hw_2` и так далее. Файл с решением в каждой такой папке будет называться `solution.ipynb`, например `hw_1/solution.ipynb`.

## Окружение проекта

Требования и зависимости заданы в [pyproject.toml](pyproject.toml), зафиксированные версии — в [uv.lock](uv.lock).

- **Python:** 3.14 или новее согласно настройкам этого проекта.
- **Менеджер зависимостей:** uv.
- **Поддержка PyCharm:** pip включён в зависимости для разработки и устанавливается при `uv sync`.
- **Ноутбуки:** JupyterLab и ipykernel.
- **Работа с данными и графиками:** pandas и matplotlib.

В разделе также есть [sample.ipynb](sample.ipynb) — заготовка Jupyter-ноутбука для практики.

## Запуск

При установленном uv из корня репозитория:

```powershell
cd Python
uv sync --locked
uv run jupyter lab
```

После запуска JupyterLab можно открыть `solution.ipynb` или создать отдельный ноутбук для задания.

## Если папка проекта была перенесена или переименована

Команды в `.venv/Scripts` могут сохранять старые абсолютные пути. Чтобы восстановить их, выполни из папки `Python`:

```powershell
uv sync --locked --reinstall
```

В PyCharm выбери интерпретатор `Python/.venv/Scripts/python.exe` относительно корня репозитория. Если сам каталог `Python` переименован, укажи его новое имя. После смены интерпретатора перезапусти сервер Jupyter и ядро ноутбука.
