# Язык Python для разработчиков

Домашние задания по дисциплине «Язык Python для разработчиков» в рамках магистратуры НИУ ВШЭ «Бэкенд-разработка и архитектура программных систем».

**Преподаватель:** Руслан Шиманский.

[Об обучении и других разделах репозитория](../README.md)

Решения и материалы будут добавляться в репозиторий по мере работы над заданиями.

## Окружение проекта

Требования и зависимости заданы в [pyproject.toml](pyproject.toml), зафиксированные версии — в [uv.lock](uv.lock).

- **Python:** 3.14 или новее согласно настройкам этого проекта.
- **Менеджер зависимостей:** uv.
- **Ноутбуки:** JupyterLab и ipykernel.
- **Работа с данными и графиками:** pandas и matplotlib.

В разделе также есть [sample.ipynb](sample.ipynb) — заготовка Jupyter-ноутбука для практики.

## Запуск

При установленном uv из корня репозитория:

```powershell
cd Python
uv sync --locked
uv run jupyter lab
```

После запуска JupyterLab можно открыть `sample.ipynb` или создать отдельный ноутбук для задания.
